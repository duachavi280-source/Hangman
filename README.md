# Hangman Game

## Project Overview

Hangman Game is a command-line based word guessing game developed using Python.

The computer randomly selects a programming or technology-related word from a predefined word list. The player guesses the hidden word one letter at a time.

The player starts with 8 lives. Correct guesses reveal letters, while incorrect guesses reduce the remaining lives and change the Hangman drawing.

The game also includes scoring, winning streaks, game statistics, instructions, and a main menu.

## Objectives

- To develop an interactive game using Python.
- To apply Python programming concepts.
- To implement random word selection.
- To implement input validation.
- To detect repeated guesses.
- To implement win and lose conditions.
- To implement a scoring system.
- To maintain game statistics.
